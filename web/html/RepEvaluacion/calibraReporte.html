    Ayuda para el uso del módulo de calibración

    El módulo de calibración de impresión consta de 3 áreas.

    • Controles
    • Coordenadas
    • Caidas de textos

    Controles

    El área de controles nos proporciona el uso de 3 botones los cuales se utilizan para realizar las siguientes operaciones.


    Imprimir rejilla

    Este boton nos proporciona la impresión de la rejilla sin las caidas de los textos mostrados.

    Imprimir hoja de prueba

    Este boton nos proporciona la impresión de una hoja de prueba la cual incluye la rejilla y las caidas de los textos mostradas actualmente. Nota: Es Importante haber guardado cambios con anterioridad !!!

    Guardar Cambios

    Con este boton guardamos los cambios actuales que realizamos durante el proceso de calibración.

    Coordenadas

    El área de coordenadas provee una lista de todos los textos requeridos para poder imprimir el Reporte de Evaluación, a la izquierda de cada texto se encuentan sus coordenadas [ H ][ V ] como lo muestra el encabezado de ejemplo; para poder cambiar las coordenadas de algún texto en específico hay que seguir los siguientes pasos:
    1.- Seleccionar el texto al que se le quiere modificar sus coordenadas.
    (Al realizar esta operación, las coordenadas que tiene actualmente son transferidas a las cajas de texto [ H ][ V ] que se encuentran a la izquierda del boton "Cambiar", así como tambien se remarcaran de color verde las coordenadas actuales dentro de la lista, para que usted sepa a que tipo de texto le esta cambiando las coordenadas).
    2.- Cambiar las coordenadas [ H ][ V ] por las que usted desee.
    3.- Despúes deberá dar click en el boton "Cambiar", para realizar el cambio de las coordenadas [ H ][ V ].
    (Al realizar esta operación usted podrá ver que en el área de "Caidas de los textos" se mostrara en color rojo el texto que usted selecciono con las nuevas coordenadas [ H ][ V ] que definio en el paso 2).

    Caidas de textos

    En esta área se muestran los textos que se imprimiran en el Reporte de Evaluación en las coordenadas [ H ][ V ] y solo se podrán modificar desde el áera de coordenadas.
